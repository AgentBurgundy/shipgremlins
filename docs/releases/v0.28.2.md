# ShipGremlins v0.28.2

Start another PM while a run is being prepared, checked, or reconciled. The
dashboard now saves the new run in the queue instead of returning "Another local
runner operation is in progress. Try again shortly."

An available verified runner picks up the queued run automatically. With one
runner, it waits for the current job to finish. Project limits, compatible-worker
requirements, and shared test-account reservations still govern pickup.

Duplicate runs for the same PM remain blocked. Accepted jobs survive a controller
restart, cancellation still works before pickup, and failed saves cannot leave an
unacknowledged job scheduled to run. Configuration changes and other controllers
remain fenced by the workspace lock.

Install through **Settings → Updates** or `gremlins update`, then restart the
controller to load the fix.
