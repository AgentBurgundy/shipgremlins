# ShipGremlins v0.25.0

Connecting a project now starts useful repository discovery as soon as its source and AI connections are ready. Setup can continue when connections recover, and missed patrols catch up once after controller downtime. The dashboard explains what is running, what is blocked and how to resolve it.

- Import supported Compose stacks from the exact repository revision into an isolated app plus Postgres 16/Redis 7 recipe. Unsupported features are reported before configuration; host mounts and Docker socket access are rejected.
- Supply public Docker build arguments separately from private, ephemeral BuildKit secrets. Build-only connections support masked multiline files without exposing them to application runtime or agent payloads.
- Recover unconfirmed dispatches by linking the existing provider run after exact scope/evidence checks. Durable CI rerun reservations reconcile lost responses and prevent duplicate requests.
- Choose a default-off, bounded low-risk approval policy for documentation, static styles and tests. Exact file lists, daily/open/file/line limits and durable approval origin remain authoritative. Send automatic tickets back to manual review directly from the audit.
- See independent source freshness, last successful refreshes, safe run-failure explanations and direct remedies. Save project favorites/order and use Ctrl/Cmd K to find projects, recent runs and setup actions.
- Use the simplified PM workspace with one contextual back action, clear work controls, responsive sections and distinct loading, empty and failure states.

This release integrates the current v0.24.2 sign-in, test-account, managed-runner, staging-sync, QA/rework and per-PM promotion behavior. Existing paused crews remain paused. Automatic ticket approval honors configured epic approval, protected-file checks, staging review and production release; it never marks work Done.

All 11 remaining backlog items are implemented. The complete [100-improvement record](../IMPROVEMENTS_100.md), [25 UI polish changes](../UI_POLISH_25.md) and [autonomy acceptance evidence](../audits/backlog-autonomy.md) are included.

Verification uses automated provider/runner scenarios and real desktop/mobile dashboard checks with disposable synthetic data. Live Docker builds and customer staging execution were not certified; Docker Desktop's Linux daemon was unavailable during that check. Provider-run association requires the evidence-enabled hub workflow; older runs without authenticated input evidence remain manual inspection cases.

Release checks passed: 3,704 tests across 214 test files (6 skipped), TypeScript, lint, formatting, dashboard bundle consistency, native integration tests, project/cron validation, and real packaged CLI installation with staged-update/rollback checks.

Install through the dashboard's Updates panel or `gremlins update`. Existing project configuration, credentials and retained work are preserved by the staged updater. Source installations can install this release by its tag.
