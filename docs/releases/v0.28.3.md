# ShipGremlins v0.28.3

Restore Codex's programmatic tool calls by enabling Code Mode and its native tool
host together. PMs and coders can use the tools admitted to their run; discovery
and independent review retain their existing read-only capabilities.

If the native tool host is unavailable, stop the run with an actionable runner
repair message. Do not silently complete an investigation without its output:
patrols and explorations must now produce all four valid knowledge documents
before their investigation and recording stages pass. The controller also rejects
missing documents from current workers and preserves the previous knowledge.

Native CLI checks exercise actual shell, file-output and MCP tool calls against a
synthetic local provider, including the read-only restrictions. No paid model
calls are required for these checks.

Install through **Settings → Updates**, restart the controller, and verify the
runner again to use the updated worker image. Update remote agent services too.
Then start a new PM run; previous incomplete runs are not automatically repeated.
