# Workspace token usage

Open **Usage** in the dashboard sidebar to see recorded AI token use across all
projects. Choose **Last 7 days**, **Last 30 days**, or **All time**, then narrow the
view to a project. Filters stay in the URL, so you can bookmark a view. Dates use
UTC, including today in the 7- and 30-day windows.

The total adds four separate categories:

- **Input:** input tokens not served from cache.
- **Output:** tokens generated by the model.
- **Cache reads:** input tokens reused from cache.
- **Cache creation:** input tokens written to cache.

These are token counts, not a cost estimate or the balance of your provider
account. Cache reads and writes may have different billing rates; the dashboard
does not convert them into dollars.

Usage updates after a run or an AI setup action finishes. It is not a live token
stream. Choose **Refresh** for the latest reports. The page includes PM and coding
runs as well as supported AI planning and setup actions. Idea planning before a
project exists appears under **Workspace planning**.

## Read coverage alongside totals

Only reported usage contributes to the totals. **—** means no measurement was
reported; it does not mean zero. A measured zero appears as **0**. Interrupted or
partial reports may omit tokens; **≥** marks an incomplete lower bound. Categories
with no reported measurement remain **—**, even when another category is known.

Older runs may have no usage report. ShipGremlins cannot reconstruct their token
counts from elapsed time, messages, or successful completion. Reporting coverage
shows which runs and AI operations supplied measurements and which remain unknown.

The trend and project table use the selected period. Long all-time trends group
adjacent days while preserving their totals. Projects recreated under the same
name retain separate usage histories; the selector can show each history or the
combined project name. Deleting a project does not turn its earlier token use into
the replacement project's use.
