# Dashboard improvements: 051–075

Audited October 14, 2026. This is the dashboard portion of the 100-improvement review. **All 25 improvements are implemented.** Existing user edits to setup, delivery, project settings, and provider setup were preserved.

The principal problems were state ambiguity and too many competing actions: Overview could prioritize an old first pull request over a live run, each project repeated a coding launcher, useful metrics disappeared until a first change existed, and initial connection guidance implied Linear was required for repository discovery.
